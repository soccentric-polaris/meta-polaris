# meta-polaris

Yocto layer for **Polaris** (Renesas RZ/G2L), part of the open-source Polaris platform from [SoCcentric](https://soccentric.com).

It is used by [Polaris-OS](https://github.com/soccentric-polaris/Polaris-OS), which holds the kas configuration that builds a full image.
